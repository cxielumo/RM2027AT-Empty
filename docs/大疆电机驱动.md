# 大疆电机驱动

驱动位于 `Components/Inc/motor_dji.h`、`Components/Src/motor_dji.c`，已加入 CMake、Keil 和 main 初始化。未注册电机时不启动任务、不发送控制帧。

## 配置

初始化由 main 启动装配完成，`motor_dji_init()` 不在公共头文件公开。应用在 `robot_main` 开始处构造配置结构体并逐个注册：

```c
static motor_dji_t motor;
const motor_dji_config_t config = {
    .id = 1,
    .bus = CAN_BUS_1,
    .model = MOTOR_DJI_M3508,
    .invert = true
};
if (motor_dji_register(&motor, &config) != 0) {
    /* 处理注册失败，例如 panic(FAULT_INIT)。 */
}
```

驱动复制配置，调用返回后结构体可以离开作用域。最多注册 `MOTOR_DJI_MAX_DEVICES`（16）个电机，使用静态存储，无动态内存分配。首次成功注册启动服务任务，后续注册复用该任务；电机默认未使能。支持运行期间追加注册，不支持注销或覆盖已有设备。注册失败返回-1，不改变已注册设备；成功返回0。必须先初始化，禁止从ISR调用。

配置包含硬件编号 id、总线、型号和反向标志 invert。invert 默认 false；设置 true 时，电流命令、速度、电流反馈和相对累计角度均反向，encoder_raw 保持物理编码器值。反向反馈遇到 -32768 时饱和为32767，避免16位溢出。电流限值由型号推导，反馈和命令超时统一100ms。id 必须与实际电调设置一致：C610/C620 为1..8，GM6020 为1..7。注册通过 bus、model、id 识别硬件，返回 motor_dji_t 句柄。后续控制和查询传入句柄指针；不同总线或无协议冲突的不同型号可使用相同 id。句柄内容由驱动写入，不应手动修改；零初始化句柄无效，失败时保留原句柄。配置被复制；电机对象必须保持有效且地址稳定，建议使用 static 或全局变量，不能复制、移动或重复注册同一个对象。非法参数、反馈/命令槽冲突、容量已满或任务创建失败时注册返回-1。

| 型号 | 命令 | 命令限值 | 反馈 ID | 命令组（ID 1..4 / 后续） |
| --- | --- | --- | --- | --- |
| M2006 + C610 | 原始电流 | ±10000 | 0x200 + ID | 0x200 / 0x1FF |
| M3508 + C620 | 原始电流 | ±16384 | 0x200 + ID | 0x200 / 0x1FF |
| GM6020 电流模式 | 原始电流 | ±16384 | 0x204 + ID | 0x1FE / 0x2FE |

协议依据：[C610 官方说明](https://rm-static.djicdn.com/tem/17348/RoboMaster%20C610%20Brushless%20DC%20Motor%20Speed%20Controller%20User%20Guide.pdf)、[C620 官方说明](https://cdn-hz.robomaster.com/robomasters/public/document/RoboMaster%20C620%20Brushless%20DC%20Motor%20Speed%20Controller%20V1.0.pdf)、[GM6020 官方说明](https://rm-static.djicdn.com/tem/17348/RoboMaster%20GM6020%E7%9B%B4%E6%B5%81%E6%97%A0%E5%88%B7%E7%94%B5%E6%9C%BA%E4%BD%BF%E7%94%A8%E8%AF%B4%E6%98%8E20231013.pdf)。GM6020 仅支持电流控制，要求固件 >=1.0.11.2、RoboMaster Assistant >=2.7，并通过调参软件打开电流环开关。

同一总线的反馈 ID 和命令槽必须唯一。C6x0 ID5..8 与 GM6020 ID1..4 的反馈 ID 存在冲突，注册会拒绝冲突配置。未配置槽始终发送0，因此连接到相同命令组的电机应全部注册。配置使用的 CAN 总线由本任务独占接收；不能让应用或其他组件竞争 `can_receive()`。

## 使用

```c
#include "motor_dji.h"

/* 在 robot_main 中调用；需先收到有效在线反馈。 */
/* 在控制循环中定期更新（间隔小于100ms）。 */
motor_dji_setCurrent(&motor, 1000);
/* GM6020 同样使用 motor_dji_setCurrent(&gimbal_motor, 1000)。 */
/* 后台任务直接更新已注册对象的 measure。 */
float speed = motor.measure.speed_rpm;
(void)speed;
if (motor.measure.online) {
    /* motor.measure.speed_rpm 为转子转速，不包含减速比换算。 */
}
/* 停止时撤销使能，下轮发送零命令。 */
motor_dji_stop(&motor);
```

控制接口仅供任务上下文使用。离线或超限命令均忽略，不暂存供恢复后使用。在线时 setCurrent 更新目标并激活输出；反馈/命令超时或 CAN 故障清零目标并停止输出，恢复后必须提交新电流命令。enabled 表示已接受命令且输出未停止。stop 无法撤回已经进入硬件邮箱的帧。

motor->measure 直接读取实时反馈，在线及超时状态由后台任务更新。需要一致地读取多字段或64位角度时，应用在任务临界区中复制 measure。应用只读 measure，不应修改驱动状态。

快照包含编码器、带符号转速/电流、温度有效性、相对角度计数、反馈时间和序号。C610 不提供温度有效值。首帧及重连首帧角度计数从0开始，后续按8192周期回绕累计；每采样超过半圈仍存在不可判别歧义。

服务任务优先级5、静态栈768 words，每总线每轮最多读取32帧；命令组轮转提交，按固定1ms周期等待（至少1 tick），超期时阻塞1 tick后重设周期基准。can_send 无发送成功状态，邮箱忙时该帧丢弃，下一轮发送最新目标。CAN 总线故障返回 -2，空队列返回 -1。

连接前确认 CAN 为1Mbps、CAN_H/CAN_L正确、共地及总线两端终端电阻。源码测试不代表板上验证，需对实际配置进行上板检查。

## 通信周期与统计

通信任务使用 `xTaskDelayUntil()` 按1ms周期安排下一轮（低tick频率时至少1 tick），处理耗时不再逐轮累加到周期中。错过周期时阻塞1 tick并重设周期基准，避免连续追赶导致其他任务无法运行。

CAN 软件接收队列丢帧和发送邮箱忙只记录，不新增停机或角度重置动作。硬件接收溢出、总线错误和电机超时仍按原有规则处理。

## 统一停机

```c
#include "motor.h"

motor_shutdown();
```

`Components/Src/motor.c` 统一关闭六路 TT 电机并清零全部已注册大疆电机的目标。TT 输出在调用中关闭；大疆零电流帧由服务任务在下一轮提交，不能撤回已有硬件邮箱帧。可重复调用，仅用于任务上下文或初始化后的调度前阶段。停机不锁存，新的显式控制可恢复输出；TT 需要重新 enable，大疆需要在线反馈及新的 setCurrent。
