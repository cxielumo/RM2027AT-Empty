主控 U3 为 AT32F423CCT7，LQFP-48。MCU 引脚名称取自原理图内嵌符号，实际网络和接口针号取自 PCB 的 PAD_NET；串联排阻两侧保留独立网络并注明连接路径。本文没有把网络归属当作 PCB 已完成布线或实板导通的证明，也没有完成原理图全部线段与 PCB 的逐网一致性检查。接口针号是封装焊盘编号，不代表从某一观察方向看到的左右顺序。

## 2. CAN 电机接口

| 总线 | TX / U3脚 | RX / U3脚 | 收发器 | 外部接口 |
|---|---|---|---|---|
| CAN1 | PA12 / 33 | PA11 / 32 | U1 | CN13、CN14、CN15 |
| CAN2 | PB13 / 26 | PB12 / 25 | U5 | CN17、CN18、CN19 |

上述 CAN 插座：1=CANH，2=CANL，3、4=GND。同一总线的三个插座并联，不是三路独立 CAN。插座没有电机电源针。

## 3. 六路板载直流电机驱动

|---|---|---|---|---|---|---|
| 1 | CN9 | U8 | TMR4_CH3 / PB8 | TMR4_CH4 / PB9 | $1N143 | $1N144 |
| 2 | CN5 | U9 | TMR4_CH2 / PB7 | TMR4_CH1 / PB6 | $1N145 | $1N146 |
| 3 | CN6 | U10 | TMR3_CH2 / PB5 | TMR3_CH1 / PB4 | $1N147 | $1N148 |

| 5 | CN8 | U12 | TMR12_CH2 / PB15 | TMR12_CH1 / PB14 | $1N151 | $1N152 |

驱动脚3=GND，脚4=VMOTOR；脚7/8与脚5/6分别为两侧输出。CN5/6/7/9/10 的脚3、4均为GND；**CN8脚3为独立网络 `$1N159`，脚4才是GND**。该网络在本次 PCB 焊盘数据中仅出现于 CN8.3，不能当成有效编码器输入。CN10 的脚1、2与 U13 两侧输出的顺序相对其他插座不同，软件方向命名应单独处理。

## 4. H1/H2/H3 扩展排针与舵机候选接口

| 列号 | H1信号，经排阻 | MCU引脚 | H2电源 | H3 |
|---|---|---|---|---|
| 1 | TMR3_CH4，经 RN1 | PB1 | $1N257 | GND |
| 2 | TMR3_CH3，经 RN1 | PB0 | $1N257 | GND |
| 3 | TMR14_CH1，经 RN1 | PA7 | $1N257 | GND |
| 4 | TMR13_CH1，经 RN1 | PA6 | $1N257 | GND |
| 5 | TMR2_CH2，经 RN2 | PA1 | $1N257 | GND |
| 6 | TMR2_CH1，经 RN2 | PA0 | $1N257 | GND |
| 7 | RX6，经 RN2 | PA5 | $1N257 | GND |
| 8 | TX6，经 RN2 | PA4 | $1N257 | GND |

H2的8针共同连接 `$1N257`，经 F1 与 +5V 相连；H3全部接地。H1前6路可作为定时器输出的硬件候选，后2路是 USART6。是否连接舵机须匹配设备电源和脉宽要求；接收机接入 H1.7（MCU RX6），H1.8是MCU TX6。USART6被用于遥控器时不应同时分配其他业务。

## 5. 串口、I²C和调试接口

| 功能 | 接口针号 | MCU引脚/网络 | 中间连接 |
|---|---|---|---|
| USART1 TX | U7.3 | PA15 / TX1 | RN3 → $1N250 |
| USART1 RX | U7.4 | PB3 / RX1 | RN3 → $1N249 |
| USART7 TX | U14.3 | PF8 / TX7 | RN4 → $1N382 |
| USART7 RX | U14.4 | PA8 / RX7 | RN4 → $1N381 |
| I²C2 SDA | U15.1 | PB11 / SDA | RN4 → $1N383 |
| I²C2 SCL | U15.2 | PF6 / SCL | RN4 → $1N384 |
| SWDIO | CN11.1 | PA13 / SWDIO | RN3 → $1N372 |
| SWCLK | CN11.2 | PA14 / SWCLK | RN3 → $1N371 |

U7.1、U14.1分别经F3、F6接+5V；两者脚2接GND。U15.3=GND，U15.4经F5接+5V。CN11.3=GND、CN11.4经F2接3V3。接口的5V电源针不代表MCU信号电平为5V。U7/U14/U15 的焊盘5、6以及CN11的焊盘5、6为接地焊盘，使用连接器资料确认机械脚与信号脚。

## 6. LED、ADC、启动和电源

- 用户确认三颗可控LED实物均为红灯。编号按原R/G/B网络顺序：LED_1（1）→PC13/U3.2→LEDR→LED1；LED_2（2）→PC14/U3.3→LEDG→LED2；LED_3（3）→PC15/U3.4→LEDB→LED3。LEDR/LEDG/LEDB仅保留为原理图网络名，不表示实际发光颜色。LED另一端经R14/R15/R16接地，连接关系支持高电平点亮设计。
- PA2/U3.12=ADC1_IN2，R21接24V、R13接GND；库标称值分别10kΩ和1kΩ，理想分压为1/11。换算母线电压应采用实际ADC参考、电阻误差及校准值。
- PA3/U3.13=ADC1_IN3；PCB焊盘网络未发现U3之外的连接，不能认定它已接外部传感器。
- SW1连接BOOT和3V3，R4将BOOT下拉至GND；SW2连接RST和GND。两者分别为启动模式键、复位键，不是普通业务按键。
- PF0/PF1接X1两端及负载电容；PA13/PA14用于SWD。
- DC5521和U2连接VBAT/GND。CN1～CN4：脚1=24V、脚2=GND，均为电源接口，没有独立GPIO控制。
- +5V、VMOTOR、3V3为不同网络；本文不将VMOTOR的网络名称解释为已测得的电压。

## 7. 与固件和Lec4目标的关系

| 项目 | 当前证据 | 实现要求 |
|---|---|---|
| LED | 固件PC13/14/15与PCB对应 | 可以沿用现有LED抽象 |
| CAN | CAN1 PA11/12、CAN2 PB12/13对应 | 增加电机协议层与反馈分发 |
| USART6遥控器 | PA4 TX6、PA5 RX6，当前100000波特率、9位含偶校验、1停止位 | 补接收缓冲、帧边界和协议解析；接线见H1 |
| PWM | 多数通道当前为TMR_OUTPUT_CONTROL_OFF | 初始化定时器不等于已配置PWM；须补PWM模式、频率及输出控制 |
| TMR2 | CH1为输入捕获；CH2为PWM_MODE_B；CH3未见输出通道配置 | CN10电机输入PB10/CH3尚需配置；改用途时同时考虑H1.5/6 |
| 定时器共享 | TMR3既接CN6又接H1.1/2；TMR2既接CN10又接H1.5/6 | 同一定时器通道共享周期，电机PWM与舵机频率需统筹 |
| 泵 | 无独立PUMP网络；PA11已接CAN1_RX | 不能照搬Lec4的PA11泵GPIO；可评估分配一路板载驱动，需明确泵型号与接口 |
| ADC | 固件转换ADC_CHANNEL_2 | 对应24V分压；IN3虽有网络名但无其他焊盘端点 |
